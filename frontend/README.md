# Frontend

This is a Vite + React frontend that displays a small operations dashboard.

## Development

```bash
npm install
npm run dev
```

## Environment Variables

- `VITE_API_BASE_URL`: backend base URL (default `http://localhost:3000`).
- `VITE_BUILD_ID`: CI build identifier.
- `VITE_AWS_REGION`: deployment region.
- `VITE_DEPLOY_STRATEGY`: deployment strategy label.
